# 추가근로시간 계산기

커넥티움 직원이 다우오피스 근태 화면의 **총 근로시간**을 넣어 본인의 월 연장근로시간을 확인하는 개인용 계산기입니다.

- 서버, DB, 로그인이 없는 정적 사이트입니다(Vite + React + TypeScript).
- 설정과 월별 기록은 각자 브라우저의 `localStorage`에만 저장됩니다. 외부로 전송되는 정보는 없습니다.

## 로컬 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # Vitest (작업 지시서 테스트 케이스 9개 포함)
npm run build    # dist/ 에 정적 파일 생성
```

## 계산 규칙

모든 계산은 분 단위 정수로 합니다. 로직은 `src/lib/overtime.ts`에 있습니다.

```
평일공휴일수 = 그 달 공휴일 중 월~금이고 '대체공휴일'이 아닌 날 수
기준시간     = 월 기준시간 − 평일공휴일수 × 1일당 차감
비교대상     = (휴일근로로 분리) max(0, 총근로 − 평일공휴일 근무)
               (합계에 포함)     총근로
연장근로     = max(0, 비교대상 − 기준시간)
남은 시간    = max(0, 기준시간 − 비교대상)
휴일근로     = 평일공휴일 근무 (0이면 표시 안 함)
```

- 주말과 겹친 공휴일은 차감하지 않습니다.
- 대체공휴일은 평일로 보고 차감하지 않습니다.

## 설정 기본값

| 항목 | 기본값 |
|---|---|
| 월 기준시간 | 173시간 |
| 평일공휴일 1일당 차감 | 8시간 |
| 평일공휴일 근무 처리 | 휴일근로로 분리 |

화면 아래 '설정'에서 바꿀 수 있고, 값은 그 브라우저에 저장됩니다.

## 공휴일 목록 갱신 (매년 말)

공휴일은 `src/data/holidays.json`에 정적으로 들어 있습니다. 매년 말에 다음 해 목록을 추가합니다.

1. 우주항공청 월력요항(관공서의 공휴일에 관한 규정 기준)에서 다음 해 공휴일을 확인합니다.
2. `src/data/holidays.json` 끝에 항목을 추가합니다.
   ```json
   {"date":"2028-01-01","name":"신정","type":"공휴일"},
   {"date":"2028-03-02","name":"대체공휴일(삼일절)","type":"대체공휴일"}
   ```
   - `date`는 `YYYY-MM-DD`, `type`은 `공휴일` 또는 `대체공휴일`.
   - 요일은 날짜로 자동 계산하므로 적지 않습니다. 주말 공휴일도 그대로 넣어 두면 됩니다(자동으로 차감 제외).
   - 회사 자체 휴무일(창립기념일 등)은 `type: "공휴일"`로 넣으면 함께 차감됩니다.
3. `npm test`로 확인한 뒤 `main`에 푸시하면 Vercel이 자동 배포합니다.

목록에 없는 연도를 고르면 화면에 "이 연도 공휴일 목록이 없어 차감 없이 계산했습니다"가 표시됩니다.

## 배포

GitHub `main` 브랜치에 푸시하면 Vercel이 자동으로 빌드·배포합니다(Framework: Vite, Build: `npm run build`, Output: `dist`).
